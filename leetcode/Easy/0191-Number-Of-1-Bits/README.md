# Number of 1 Bits

**Difficulty:** Easy  
**Topics:** Divide and Conquer, Bit Manipulation  
**LeetCode URL:** [Number of 1 Bits](https://leetcode.com/problems/number-of-1-bits/)

## Problem Description

<p>Given a positive integer <code>n</code>, write a function that returns the number of <span data-keyword="set-bit">set bits</span> in its binary representation (also known as the <a href="http://en.wikipedia.org/wiki/Hamming_weight" target="_blank">Hamming weight</a>).</p>

<p>&nbsp;</p>

## Solution

```java
// LeetCode Problem: Number of 1 Bits
// Link: https://leetcode.com/problems/number-of-1-bits/
// Difficulty: Easy
// Language: java

class Solution {
    public int hammingWeight(int n) {
        int count = 0;
        while(n!= 0){
            n = n & (n-1);
            count++;
        }
        return count;
    }
}
```
