## 📱 NIRVANA — Android APK (prototype)

Download **`nirvana-release.apk`** below.

### Install
1. Transfer the `.apk` to an Android device (Android 7.0 / API 24 or newer).
2. Tap it and allow **"Install from unknown sources"** when prompted.
3. Open **NIRVANA** and follow the short onboarding.

> This is a hackathon prototype build. It is **signed with a debug key**, so
> Play Protect may warn you — choose **"Install anyway"**. Expected, not a bug.

### What works fully in this build
- 🔔 Offline exact reminders (medication / hydration / meals) with **Done · Snooze 15 min · Later today** actions
- 🧩 All three cognitive engagement games with non-penalizing hints
- 🆘 "I'm Lost / I Need Help" live location sharing
- 👨‍👩‍👧 Caregiver dashboard, pairing, and 7-day participation view
- 🌍 Multi-language support

💡 **Try airplane mode.** The elder experience keeps working offline — that is the point.
